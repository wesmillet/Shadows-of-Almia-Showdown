# Nightfall Royale

A browser demo: a Pokémon battle royale using Pokémon Mystery Dungeon
(PMDCollab SpriteCollab) character sprites over hi-res painted terrain.
TypeScript, Vite, Canvas 2D with a WebGL lighting pass. Non-commercial fan
project; see `assets/CREDITS.md`.

```
npm install
npm run dev        # http://localhost:5173/
npm test           # Vitest unit tests
npm run build      # typecheck + production build into dist/
```

Full documentation (asset layout, adding a Pokémon, swapping in a painted
tileset) is written up at the end of the build; see `docs/plan.md` for the
milestones.
