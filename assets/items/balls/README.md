# Overworld item balls

16 ground-item sprites (18x18, transparent), both as single files and packed in
`balls_strip.png` (20x24 cells, bottom-centre anchored, order in manifest.json).

poke, great, ultra, master, net, dive, nest, repeat, timer, luxury, premier, dusk,
heal, quick, cherish, plus `vial.png` (a purple flask, unidentified; use for a
special or quest item).

These are the item-ball sprites drawn on the ground. Capture throws use the same
art scaled; the open and wobble frames are built in code from the closed sprite.
