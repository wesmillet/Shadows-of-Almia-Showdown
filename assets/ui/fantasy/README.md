# Menu frames

Kenney's **Fantasy UI Borders** (https://kenney.nl/assets/fantasy-ui-borders), CC0.
White 48x48 frames with 2 px lines, tinted in code (`src/ui/pixelUi.ts`) and
drawn as 9-slices over dark fills:

| file | used for |
| --- | --- |
| border_011 | HUD panels and screen panels |
| border_002 | popups (shop, item found, learn a move) and bag slots |
| border_000 | buttons |
| border_009 | tabs |
| border_024 | the armed bag slot (gold) |
| panel_000 | the main button (filled) |
| divider_000 | spare |
