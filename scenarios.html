Scaling playtest

Prototype build (scaling-lab branch). Each scenario sets both teams exactly and holds the storm off; the same seed gives the opponents the same dice, so you can replay one and try it under the other scaling. Trainer battles start a second in: steer with the mouse and keys as usual, Space to dodge. In the open-world ones the wild Pokémon come at you. The banner shows the time, the result and how many moves each side got off.

Same seed: same opponents' dice.
